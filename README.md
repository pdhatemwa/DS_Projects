### 🔰 My First Machine Learning Project
I’m starting with a simple but powerful project:

The goal of this project is to:
- Understand the end-to-end workflow of a data science project.
- Explore and clean real-world data.
- Build a basic machine learning model to predict housing prices.

This will cover:
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Model training and evaluation

This is just the beginning—more projects, insights, and lessons are coming as I grow.
